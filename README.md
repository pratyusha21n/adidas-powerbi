# Adidas US Sales Analysis – Power BI Project

## Overview

This project is an interactive **Power BI Sales Analytics Dashboard** built using Adidas US sales data. The dashboard provides detailed insights into sales performance, profit analysis, product trends, retailer performance, and regional sales distribution.

The objective of this project is to transform raw sales data into actionable business insights using Power BI, DAX calculations, data modeling, and interactive visualizations.

This project simulates a real-world retail sales analytics environment and demonstrates practical business intelligence and data visualization skills required for **Data Analyst** and **Business Intelligence Analyst** roles.

---

# Business Problem

Retail companies generate large volumes of sales data across multiple regions, retailers, and product categories. Without proper analysis, it becomes difficult to identify profitable products, optimize sales strategies, and improve business performance.

This project helps answer key business questions such as:

* Which regions generate the highest sales and profit?
* Which products contribute most to revenue?
* Which retailers perform best?
* How do sales trends vary over time?
* Which sales methods drive maximum revenue?
* How can business decision-making be improved using data insights?

# DAX Measures Used

Examples of DAX calculations used in the project:

```DAX
Total Sales = SUM(Sales[Total Sales])
```

```DAX
Total Profit = SUM(Sales[Operating Profit])
```

```DAX
Units Sold = SUM(Sales[Units Sold])
```

```DAX
Average Margin = AVERAGE(Sales[Operating Margin])
```
